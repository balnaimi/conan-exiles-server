Quick Start

Fast Start
Use a small .env file with only the basic settings. Good for testing or getting a simple server online quickly.
mkdir conan-server && cd conan-server
curl -O https://raw.githubusercontent.com/balnaimi/conan-exiles-server/main/docker-compose.yml
curl -o .env https://raw.githubusercontent.com/balnaimi/conan-exiles-server/main/.env.minimal
nano .env
docker compose up -d
First-run and update duration depends on storage, memory, CPU, network speed, and cache state. The minimal .env uses mostly default server settings.
Full Configuration
Use the full .env.example template if you want every documented setting available for editing.
mkdir conan-server && cd conan-server
curl -O https://raw.githubusercontent.com/balnaimi/conan-exiles-server/main/docker-compose.yml
curl -O https://raw.githubusercontent.com/balnaimi/conan-exiles-server/main/.env.example
cp .env.example .env
nano .env
docker compose up -d
Use Config Generator
Use the visual config generator (⚙️ Config Generator tab), save the generated output as .env in the same folder as docker-compose.yml, then start the server.
mkdir conan-server && cd conan-server
curl -O https://raw.githubusercontent.com/balnaimi/conan-exiles-server/main/docker-compose.yml
# Save the generated config as .env in this folder
docker compose up -d

Connecting to Your Server

How to connect:
Use Direct Connect in Conan Exiles Enhanced → Enter your server IP and port 7777 (IP only, no hostname)
⚠️ Important: Conan Exiles Enhanced does not support hostnames — you must use an IP address.
CG-NAT / Tunnels: If your server is behind CG-NAT, a tunnel, a VPS port forward, or a host with multiple network interfaces, set MULTIHOME to the public or forwarded IP address that players should use. The container will also use that value for MULTIHOMEHTTP so server-browser registration comes from the same IP. Leave both empty for normal hosting.
⏱️ First Run and Updates: SteamCMD downloads and verifies the Enhanced server, while major game updates may download several gigabytes and require temporary disk space. Startup time depends on storage, memory, CPU, and cache state—verify the readiness markers instead of relying on container uptime alone.

💻 System Requirements

Enhanced / UE5 guidance: Conan Exiles Enhanced requires substantially more memory and storage than the previous UE4 dedicated server. Older Conan Exiles hardware recommendations are not reliable sizing guidance for the current Enhanced server running through Wine.
Server Profile CPU RAM Disk
Test / very small 4 modern cores 16 GB 70 GB minimum
Small private server (up to 10 players) 4+ fast cores 16 GB recommended 100 GB recommended
Growing or modded server 6+ fast cores 24 GB or more 100 GB or more

These are practical planning recommendations for the Enhanced Windows server running through Wine—not official hard limits. Actual usage depends on the map, database, buildings, players, mods, and game updates.

Verified Runtime Observation

A clean, unmodded server using Steam build 24383534 and Wine Staging 11.10 repeatedly entered an OOM restart loop on an 8 GB host. With 16 GB, the same server reached InProgress, responded to Source/A2S queries on UDP 27015, and stabilized at approximately 9.1 GB idle memory.
8 GB RAM should be considered insufficient for the current Enhanced server. Use at least 16 GB unless you have verified your own workload under stricter limits.
Storage guidance:
  • Allow space for Docker layers, SteamCMD staging, extracted server files, databases, backups, logs, mods, and update temporary files
  • 35–40 GB total storage is not sufficient for reliable Enhanced updates
  • Allocate at least 70 GB; 100 GB is recommended for comfortable maintenance
Network:
  • Stable internet with at least 10 Mbps upload recommended
  • Lower upload speeds may cause rubber-banding and lag
  • Each connected player uses roughly 30-60 KB/s of bandwidth
Good to know:
  • Wine adds CPU and memory overhead compared with native Windows
  • Game logic benefits heavily from fast single-core performance
  • RAM usage grows as players build and explore — monitor with docker stats
  • Mods may substantially increase startup time, memory use, and storage
  • No physical GPU required — the dedicated server is headless

Mods

What you do:
Add the Steam Workshop mod IDs you want to SERVER_MOD_LIST in your .env file or in the Config Generator. Use commas between IDs and keep them in the required load order.

Finding Workshop IDs

Open the Conan Exiles Steam Workshop. A mod page URL normally ends with ?id=1234567890; copy only that numeric ID.

https://steamcommunity.com/sharedfiles/filedetails/?id=3719513784
# Workshop ID: 3719513784

Setting the Load Order

SERVER_MOD_LIST=3719513784,3720904511,3361295718
Load order matters: Keep dependencies before the mods that depend on them, and follow each mod author's instructions. Changing the order can affect an existing world.
What the container does automatically:
On startup, it downloads or updates each mod, copies the downloaded .pak files into ConanSandbox/Mods, and generates ConanSandbox/Mods/modlist.txt in the same order.

Apply, Update, or Remove Mods

# After changing SERVER_MOD_LIST
docker compose down
docker compose up -d
docker compose logs -f
  • To update mods, restart the container; configured Workshop items are checked during startup.
  • To remove a mod, delete its ID from SERVER_MOD_LIST, restart, and verify the generated modlist.txt.
  • Back up your world before removing gameplay/content mods from an existing server.
  • After an Enhanced game update, confirm that every mod supports the current build before opening the server to players.
If startup stops: Check docker compose logs. An invalid ID, missing Workshop download, missing .pak, or incompatible mod can stop startup rather than silently launching with an incomplete list.
Leave SERVER_MOD_LIST empty to run an unmodded server.

🔄 Updating

Game Auto-Update

The game files (Conan Exiles Enhanced server) are automatically updated via SteamCMD on every server restart. No manual action needed!

Docker Image Update

When a new version of the Docker image is released (new Wine, scripts, or settings), update with:

docker compose pull          # Download latest image
docker compose down          # Stop current server
docker compose up -d         # Start with new image
Your game data and saves are stored in Docker volumes — they are preserved during image updates.

Startup Troubleshooting

On some VPS or headless hosts, Wine/Conan may log Vulkan or EGL runtime messages during startup.

Failed to load libvulkan.so.1
Failed to load libEGL.so.1
Use the latest image first. It includes Vulkan, EGL, OpenGL, and Mesa runtime libraries needed by Wine and Conan Exiles Enhanced on headless hosts.
docker compose pull
docker compose down
docker compose up -d

The Log Stops at pakchunk0

Mounted Pak file '../../../ConanSandbox/Content/Paks/pakchunk0-WindowsServer.pak'
This line means pakchunk0 mounted successfully. It does not mean the server is still downloading or unpacking that file. A healthy test system progressed from this mount to InProgress within a few seconds.

Normal readiness evidence includes:

Success! App '443030' fully installed.
Match State Changed from WaitingToStart to InProgress
Engine is initialized. Leaving FEngineLoop::Init()
Started SourceServerQueries on port 27015
Do not rely on container uptime or the final stdout line alone. Query UDP port 27015, inspect the actual process tree, and check memory limits, Docker OOM events, CPU virtualization, and the host kernel.

Runtime Diagnostics

docker compose ps
docker stats --no-stream
docker inspect conan-exiles-enhanced \
  --format 'status={{.State.Status}} oom={{.State.OOMKilled}} restart={{.RestartCount}}'
docker events --since 30m \
  --filter container=conan-exiles-enhanced
docker top conan-exiles-enhanced \
  -eo pid,ppid,stat,pcpu,pmem,wchan:32,comm,args
Wine wrapper processes may normally wait in pipe_read or anon_pipe_read. Verify the actual ConanSandboxServer-Win64-Shipping.exe process and its GameThread before concluding that Wine is hung.
free -h
grep -E 'CommitLimit|Committed_AS' /proc/meminfo
sysctl vm.overcommit_memory

RAM Increased but Docker Still Shows the Old Limit

After resizing a VM or container, restart Docker and verify that Docker and the host report the same total memory:

sudo systemctl restart docker
docker info --format '{{.MemTotal}}'
free -b

Exit Code 137

Exit code 137 means the process received SIGKILL, but it does not prove OOM. OOMKilled=true or an explicit Docker oom event confirms memory exhaustion; OOMKilled=false may mean Docker killed Wine after the stop timeout.
docker inspect conan-exiles-enhanced \
  --format 'exit={{.State.ExitCode}} oom={{.State.OOMKilled}}'
docker events --since 30m \
  --filter container=conan-exiles-enhanced
If clients cannot connect after a UE4 → UE5 migration, inspect Engine.ini and remove stale bUseBuildIdOverride / BuildIdOverride lines.

💾 Backup Your Data

Before any major changes, back up your server data. This command creates a timestamped backup of your game saves:

docker compose down
docker run --rm \
  -v conan-server_config-data:/data \
  -v $(pwd):/backup \
  alpine tar czf /backup/conan-saves-$(date +%F).tar.gz /data
docker compose up -d
⚠️ Volume Name: The volume name depends on your folder name. If your folder is named my-server, the volume will be my-server_config-data.
Use docker volume ls to see your actual volume names.
Conan Exiles Enhanced uses ConanSandbox/Saved/game_0.db as the default world database; older UE4 scripts that target game.db should be updated or verified.

♻️ Restore From Backup

To restore from a previous backup (replace YYYY-MM-DD with your backup date):

docker compose down
docker run --rm \
  -v conan-server_config-data:/data \
  alpine sh -c "rm -rf /data/*"
docker run --rm \
  -v conan-server_config-data:/data \
  -v $(pwd):/backup \
  alpine tar xzf /backup/conan-saves-YYYY-MM-DD.tar.gz -C /
docker compose up -d
⚠️ Warning: This deletes all current data in the volume before restoring. Make sure you have the correct backup file!

🗑️ Full Reset (Start Fresh)

Want to wipe everything and start from scratch? This removes all game files, databases, and player data:

docker compose down -v       # Stop + delete ALL volumes
docker compose up -d         # Fresh start (re-downloads the full server)
⚠️ DANGER: The -v flag permanently deletes all game data, player saves, and buildings. There is no undo. Back up your data first if needed!

⚠️ Enhanced Setting Status / Legacy Compatibility Notes

The official Conan Exiles Enhanced server settings reference is the first source to check, but it is non-exhaustive. Absence from that list does not prove a setting is broken; it means the key still needs runtime verification on Enhanced before this project describes it as reliable.

Officially documented in Enhanced

Setting Status Details
CraftingCostMultiplier ✅ Official Enhanced key Official Enhanced docs list this key, default 1.0f, Requires Restart: No. Runtime gameplay testing is still welcome.
PlayerStaminaRegenSpeedScale ✅ Official Enhanced key Official Enhanced docs list this key, Requires Restart: No. Keep Admin Panel/database caveats in mind if a running world appears to ignore changes.

Prefer Enhanced key / legacy alias uncertain

Setting Status Details
StaminaCostMultiplier ✅ Preferred Enhanced key Preferred/current key in the official Enhanced docs for stamina cost per action.
PlayerStaminaCostMultiplier ⚠️ Legacy alias uncertain Older hosting docs mention it, but Enhanced docs prefer StaminaCostMultiplier. Do not prefer this unless runtime testing confirms a specific need.
PlayerStaminaCostSprintMultiplier ⚠️ Legacy key Not found in the official Enhanced settings reference; needs Enhanced runtime verification.

Not found in official Enhanced docs / runtime test needed

Setting Status Details
PlayerEncumbranceMultiplier ⚠️ Needs runtime test Legacy reports say it had no effect. Not found in the official Enhanced settings reference; needs runtime testing on Enhanced.
PlayerSprintSpeedScale ⚠️ Needs runtime test Present in older references and hosting docs, but not found in the official Enhanced settings reference.
PlayerMovementSpeedScale ⚠️ Needs runtime test Historically inconsistent and not found in the official Enhanced settings reference. Enhanced docs list PlayerMovementAccelerationMultiplier (BP) instead.
PlayerHealthRegenSpeedScale ⚠️ Needs runtime test Present in older/hosting references, but not found in the official Enhanced settings reference; may require Admin Panel or database-aware testing.
💡 Workaround: For unreliable settings, log into your server as Admin (ESC → Settings → Server Settings → Make Me Admin), then change the values from the in-game Admin Panel. Settings changed in-game are saved to the game database and take priority over the .ini file.
⚠️ Important: This Docker image rewrites ServerSettings.ini on every restart from your .env file. If you change settings via Admin Panel, they are stored in the game database and may take priority — but the .ini file will still show your .env values. If a legacy setting appears to do nothing, remove it from your .env to avoid confusion.

This is a community Docker wrapper for hosting a Conan Exiles Enhanced dedicated server. It is built for people who want a practical Docker Compose setup with automatic game downloads, environment-based configuration, Steam Workshop mod support, and a web-based .env generator.
