🐧 Native Linux

Starting a new server? Use Native Linux. It runs the upstream Linux server without Wine and uses fresh Native volumes.

Do not attach Wine volumes. Existing servers must use the migration path.
mkdir conan-native && cd conan-native
curl -O https://raw.githubusercontent.com/balnaimi/conan-exiles-server/main/docker-compose.native.yml
curl -o .env https://raw.githubusercontent.com/balnaimi/conan-exiles-server/main/.env.minimal
nano .env
docker compose -f docker-compose.native.yml up -d

Verify: docker compose -f docker-compose.native.yml ps

🍷 Wine

For existing Wine servers and backward compatibility. The latest channel remains Wine so current deployments are never switched automatically.

cd /path/to/existing-wine-server
docker compose pull
docker compose up -d

Verify: docker compose ps

Already running Wine?

Do not change the image tag or reuse the Wine volumes. Run the migration plan while Wine is still running. After review, run apply; apply owns the stop, creates a verified SQLite snapshot, and starts Native with separate volumes.
